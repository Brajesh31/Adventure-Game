# Contributing

1. Read the README and inspect the TypeScript source before changing behavior.
2. Keep changes focused and preserve the interactive command-line flow.
3. Install dependencies with `npm ci`.
4. Compile and manually exercise the game, including cancellation and invalid input.
5. Do not commit secrets, generated caches, or editor metadata.

Pull requests should explain the behavior changed, commands run, and any terminal or compatibility considerations. Add automated tests when introducing reusable game logic.
