# 🧭 Adventure Game Support Guide

## Start here

- [README](README.md): quick setup and project overview.

- [Installation](docs/installation.md): Node.js and npm setup.

- [Testing](docs/testing.md): manual validation.

## Choose the right channel

| Need | Channel |
|---|---|
| Gameplay defect | GitHub issue with reproduction steps |
| TypeScript compilation failure | Include command and compiler output |
| Prompt or terminal problem | Include terminal and OS details |
| Feature idea | GitHub issue describing expected behaviour |
| Documentation correction | Focused issue or pull request |
| Security vulnerability | Private report through SECURITY.md |

## Information to include

When reporting a problem, include Node.js version, npm version, operating system, terminal application, command used, steps to reproduce, expected result, actual result, and relevant error output.

Use fictional names and test values only. Remove secrets and private data from logs.

## Support boundaries

This is a best-effort educational project. No hosted game service, online account, multiplayer service, or guaranteed response time is provided.
